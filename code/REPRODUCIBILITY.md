# Reproducing Every Reported Result and Figure

Run all commands from the root of the `submission` folder.

## One-command audit

```bash
./.venv/bin/python reproduce_all_reported.py
```

This command:

1. Reconstructs the reported Table 1 test metrics from packaged model
   summaries.
2. Recomputes external Akay agreement metrics from per-record comparison CSVs.
3. Reconstructs and verifies the reported Table 1 model-comparison metrics.
4. Regenerates the computational graph figures used by the paper.
5. Reconstructs the token-context PCA from its saved vectors.
6. Confirms that generated graph artifacts are readable staged image files.
7. Recomputes the complete Table 3 candidate ranking.

Outputs are written below `outputs/`.

## Full selected-model retraining

To additionally retrain the selected model and verify exact model tensors,
metrics, ranking, external comparison, and graphs:

```bash
./.venv/bin/python reproduce_all_reported.py --retrain-selected
```

This is the strongest end-to-end reproducibility check. On the reference CPU
environment it completes in under one minute, although runtime is
machine-dependent.

## Individual commands

Verify all reported quantitative results:

```bash
./.venv/bin/python verify_reported_results.py
```

Regenerate and verify computational graph figures:

```bash
./.venv/bin/python reproduce_reported_figures.py
```

Recompute the final Table 3 ranking:

```bash
./.venv/bin/python reproduce_predictions.py
```

Retrain and verify the selected final model:

```bash
./.venv/bin/python reproduce_experiment.py --render-graphs
```

## Result provenance

The reported Table 1 comparison is not accepted as its own evidence. The
verification script reconstructs:

- Table 1 test R2, RMSE, and MAE for the embeddings-only, nearest-neighbour,
  availability, selected hybrid, unoptimised DNABERT-2, and optimised
  DNABERT-2 configurations.

The recomputed values must exactly match the rounded values in
`training/artifacts/model_comparison/reported_table1_model_comparison.csv`.

The two values explicitly stated in the Results text are also checked:

- Selected 6-mer model test R2: `0.702`
- Optimised DNABERT-2 model test R2: `0.687`

## Figure provenance

Computational figures are regenerated by `dissertation/graphs.py` from copied
CSV, JSON, prediction, and embedding artifacts.

The context-dependent 6-mer PCA is reconstructed from
`training/artifacts/embedding_context_experiment/same_6mer_token_context_vectors.csv`.
The original model checkpoint is therefore not required merely to redraw the
reported PCA.

Static biology illustrations and concept diagrams in the dissertation PDF are
not reproduced by the code package. The figure reproduction command only
regenerates graph artifacts from the packaged data and checks that the staged
images are readable. The dissertation LaTeX source is intentionally not
included or modified by this code submission.

## Exploratory fine-tuned artifacts

Exploratory fine-tuned summaries and per-record prediction tables are retained
as supplementary artifacts, but they are not part of the reported Table 1
comparison in the dissertation. Multi-gigabyte fine-tuned checkpoints are
intentionally excluded.

The selected final frozen-embedding model checkpoint is included and can be
retrained exactly using the command above.
